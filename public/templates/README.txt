Place your converted DOCX worksheet template here as:

nursing-process-template.docx

This app exports filled worksheets using this fixed default template path:
/templates/nursing-process-template.docx

Why: this preserves your exact worksheet formatting while only replacing placeholders.

If you currently have a legacy .doc file, convert it once to .docx.

Example conversion command (macOS with LibreOffice):
soffice --headless --convert-to docx --outdir public/templates "Nursing Process Worksheet with Drug Log.doc"

Then rename the output file to:
public/templates/nursing-process-template.docx
